# Hello!

Welcome to the example-three-tier-application repository! 👋

This is a reference implementation that demonstrates how to build a modern web application with a clean separation of concerns across three tiers:

- **Frontend**: A Next.js application with React
- **Backend**: An Express REST API
- **Database**: PostgreSQL for data persistence

## What can you do here?

This project is designed to help you understand:

- How to structure a multi-tier application
- How to containerize services with Docker
- How to orchestrate multiple services with Docker Compose
- How to deploy to Google Cloud Platform using Terraform

## Getting Started

The easiest way to get started is to run the application locally:

```bash
docker compose up --build
```

Then open [http://localhost:3000](http://localhost:3000) in your browser and start exploring!
