# Project Overview

• **Three-tier web application** — A reference implementation featuring a Next.js frontend, Express REST API, and PostgreSQL database that demonstrates how to build modern full-stack applications with clean separation of concerns.

• **Local development with Docker Compose** — Run the entire stack locally with a single command (`docker compose up --build`), with automatic database migrations and health checks, making it easy to develop and test all components together.

• **Production-ready deployment to Google Cloud** — Includes Terraform infrastructure-as-code for provisioning to Google Cloud Platform (Cloud Run for services, Cloud SQL for the database), enabling scalable cloud deployments with minimal configuration.
